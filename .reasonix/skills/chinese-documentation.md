# 中文技术文档写作规范

## 概述

中文技术文档最常见的问题不是内容不够，而是**读起来别扭**——中英文挤在一起没有空格、全角半角混用、一股机翻味。本技能提供一套完整的中文技术文档写作规范。

**核心原则：** 排版服务于阅读体验，规范服务于一致性，内容服务于读者。

## 中文排版规范

### 空格

**中英文之间加空格：**
```
# 好
使用 Git 进行版本管理，配合 Jenkins 实现持续集成。

# 坏
使用Git进行版本管理，配合Jenkins实现持续集成。
```

**中文与数字之间加空格：**
```
# 好
本次更新包含 3 个新功能和 12 个 Bug 修复。

# 坏
本次更新包含3个新功能和12个Bug修复。
```

### 标点符号

- 中文内容使用全角标点（，。！？）
- 英文和数字使用半角标点
- 中英文混排时，中文使用全角标点

### 术语处理

- 保留共识英文术语（API、Git、JSON 等），不翻译
- 不要生造翻译（如把"deployment"硬翻成"部署物"）
- 首次出现时可在括号内注明英文原文
