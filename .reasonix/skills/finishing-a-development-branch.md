# 完成开发分支

## 概述

通过提供清晰的选项并执行所选工作流来引导开发工作的收尾。

**核心原则：** 验证测试 → 检测环境 → 展示选项 → 执行选择 → 清理。

## 流程

### 步骤 1：验证测试

运行项目的测试套件，确保测试全部通过。

### 步骤 2：检测环境

确定工作区状态（worktree vs 普通仓库）。

### 步骤 3：展示选项

根据环境状态展示合适的选项菜单：
- 合并到主分支
- 创建 Pull Request
- 保留 worktree 并切换到新任务
- 清理 worktree

### 步骤 4：执行选择

执行用户选择的选项。

### 步骤 5：清理

完成后清理。
